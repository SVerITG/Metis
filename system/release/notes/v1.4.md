## Metis 1.4 — your data, learnt from your code

**New: Data Memory.** Tell Metis where your R scripts live and it learns your datasets from the code alone — never by opening a data file. It knows which files you have and where, the columns your scripts use and the values they test for, how your derived variables are built, and which figures and tables you already make. When you ask for a new analysis, it writes an R script for you to run on your own computer, starting from your own closest script and your own paths.

- **Setup asks where your scripts are** (new step 5). Already installed? Open the new **Data** page in the dashboard and add a folder there.
- **Data page** — search your files, see their columns and values, and keep a note about any dataset ("fixed list — do not update"); Claude gets that note whenever the data comes up.
- **Works by itself** — in Claude Code and Claude Desktop, a request about data switches Metis into this protected mode; you do not need to type anything.

**Also in 1.4**
- Morning briefing through Claude Desktop: setup can schedule it on your own subscription, no API key needed.
- Institute editions with their own pack of templates and actions.
- Fixed: the web setup wizard could not get past step 1.

**Install:** download `MetisSetup-1.4.exe` below and run it. **Update:** in Claude Desktop, ask "update Metis".

After updating, quit and reopen Claude Desktop so the new tools load.

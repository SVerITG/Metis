A tour of Metis

Metis has two halves: this dashboard, where your work is laid out, and Claude (Desktop or Code), where you talk to it. They share one memory — what you do in one shows up in the other. Part 2 — talking to Metis in Claude Desktop

  1. Open Claude Desktop. Setup already connected Metis to it — use the "Metis — Open AI" shortcut. If Claude Desktop was open during setup, quit it fully (also from the tray icon) and open it again so it picks Metis up.
  2. Check that Metis is there. In the message box, open the tools menu (the sliders or "+" icon): metis-rc should be listed and switched on.
  3. Just ask, in plain words. Metis picks the right specialist itself. For example:
    • "What's on my plate today?"
    • "Find recent papers on my main topic and tell me which matter for my project."
    • "I just had a meeting — here are my notes. Pull out the decisions and tasks."
    • "Review the methods section I'm pasting below."
  4. Use the ready-made prompts. The "+" menu in the message box has a Metis section: metis (route any request), metis-morning (your briefing), metis-capture (save an idea or task), metis-doctor (is everything working?), and one per specialist.
  5. Watch it land here. A task Claude creates appears on Work, a paper it finds appears in the Library, and the work it did shows on the Metis tab.
  6. Using Claude Code instead? Open a terminal in your Metis folder and run claude. The same tools and memory are available there.

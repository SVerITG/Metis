## Metis for ITM

### New in 1.2
- **Your data, learnt from your code.** Setup now asks where your R scripts
  live. Metis learns your datasets from the code alone — never by opening a data
  file — and, when you ask for an analysis, writes an R script for you to run on
  your own computer, starting from your own scripts. Already installed? Open the
  new **Data** page in the dashboard and add a folder there.
- The morning briefing can be scheduled in Claude Desktop during setup.
- Fixed: the web setup wizard could not get past its first step.

A research companion for everyone at the Institute of Tropical Medicine: Claude
with a memory of your work, the institute's own templates and procedures, and a
research dashboard.

### Install (Windows)
Download **`MetisSetup-ITM-….exe`** below and run it. No administrator rights,
no Python needed — setup fetches what it needs. It asks what you work on, which
methods you use and what you want followed in the news; everything Metis shows
is built from those answers. Nothing is pre-loaded.

Windows SmartScreen may warn that the installer is from an unknown publisher (it
is not code-signed yet): choose *More info → Run anyway*.

### The ITM section
At the top of the dashboard, and in Claude Desktop's Metis menu:
- **Prepare an IRB submission** — describe your study; Metis asks what the
  committee needs, drafts the cover letter on the institute's template and lists
  the documents to enclose. It never decides the research type for you.
- **Make an ITM presentation** and **Make an ITM poster**, on the institute's
  templates.
- The templates themselves, to download.

### You need
- Windows 10 (1809) or later
- [Claude Desktop](https://claude.ai/download), with a Claude account
- An Anthropic API key is optional and paid separately; without one, Claude
  Desktop writes your morning briefing

Your files and database stay on your computer; what you ask Claude is processed
by Anthropic's Claude service.
